## Character Lock

Consistency is decided before the first clip. I build a character sheet first — Character Lock: a locked face, outfit and turnaround, plus locked locations and light. Every shot prompt repeats those locks word for word, so the person, product and room don't drift.

Every clip starts from that sheet, never from scratch.

The full method: [Character Lock](https://hafiz-afaq-portfolio.vercel.app/services/character-lock/)
